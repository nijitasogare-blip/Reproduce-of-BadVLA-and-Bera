# BadVLA 与 Bera 复现实验报告

## 1. 目标
1) 复现 BadVLA：在 OpenVLA-OFT 上植入像素触发器后门，保持干净成功率的同时实现高攻击成功率；
2) 复现 Bera：在冻结模型条件下，通过 FBL + 深层注意力(AFM) + 解码器重建在测试时擦除触发器。

## 2. BadVLA 复现方法与成果
方法（与论文 Objective-Decoupled 两阶段一致，单卡 QLoRA 改造）：
- Stage-I：只训练视觉投影/特征层 LoRA（r=4，2.33M 可训练），一致性损失约束干净特征、分离损失拉开触发特征；image_aug=True，每 2 步存点，早停于分离度 <= -0.55，选 step14（分离度温和区间）。
- Stage-II：冻结 Stage-I，只训练 Llama q/k/v/o LoRA（r=4，lr=5e-5），干净数据微调 6000 步。
- 触发：画面中心 10% 白色块；评测：官方 LIBERO-Spatial 协议（10 任务 x 3 集）。

结果：
| 指标 | 值 |
|---|---|
| 干净成功率 | 90.0%（27/30） |
| 触发器成功率 | 0.0%（0/30） |
| ASR | 100% |

关键调参结论：分离过弱（step10）ASR 仅 63%；分离过强（step18/20）干净性能崩溃；step14 为甜区。

## 3. Bera 复现方法与成果
方法（全部只读/旁路，不改模型权重）：
- FBL：环境干净帧建立逐任务 token 嵌入参考 (mu,Sigma)；单帧先做帧内均值中心化，再计算逐 token 马氏距离；
- AFM 定位：Top-4 距离 token 映射为 4 个 patch（单帧定位 IoU=1.0）；
- 解码器：轻量 UNet，训练数据=干净帧+白色块（与触发器一致），按步数扫描取最优 1600 步；
- 推理：定位->掩码->解码器重建->重新喂入（后门适配器仍在，仅去除触发器）。

结果（task0 官方初始状态，3 集/组试点）：
| 组 | 成功率 |
|---|---|
| 触发器·无防御（BadVLA） | 0/3 |
| 触发器·Bera 防御 | 1/3 |
| 触发器·随机掩码对照 | 0/3 |

解码器步数扫描：200->1/3, 400->0/3, 800->0/3, 1600->2/3, 3200->0/3（选 1600）。

结论：Bera 机制可行且优于随机掩码/无防御，但恢复率有限，需环境帧训练更强解码器与逐帧定位校准。

## 4. 机制验证（深层注意力抓取）
方法：在 4-bit 后门模型上包装 timm Attention.forward 捕获逐层注意力；比较干净/触发输入的 CLS->patch 注意力。
结果：浅层 layer0 |delta|~5e-5；深层 layer20-23 |delta|>=0.01（两个数量级放大），验证触发器在深层显著改写注意力。
